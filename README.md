# Banking Transaction API

A simple banking application built with Python, Flask, Pandas, and SQLite.

## Features

- Stores and retrieves sample banking transactions.
- Calculates total deposits, withdrawals, and net balance changes.
- Exposes transaction data through REST API endpoints.
- Tests API responses and validates transaction calculations.

## Technologies

Python, Flask, Pandas, SQLite, REST APIs

## Example Results

- Sample transactions: 5
- Completed transactions: 4
- Total deposits: $1,050
- Total completed withdrawals: $100
- Net balance change: $950

## How to Run

Install the required libraries, run the notebook cells in order, and use the Flask test client to test the API endpoints.

*Note: This project simulates banking transcations using fictional data.*
